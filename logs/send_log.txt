## 🔥 重大バグ発見と修正

### 問題: bcrypt 5.0.0 / passlib 互換性エラー

E2Eテスト実行中に、**全ての認証エンドポイントが500エラーで動作不能**であることを発見しました。

**エラー内容**:
```
ValueError: password cannot be longer than 72 bytes, truncate manually if necessary
```

**根本原因**:
- passlib 1.7.4がbcrypt 5.0.0の内部API変更に対応していない
- passlib.CryptContext使用箇所で全てエラー発生

**影響範囲**:
- POST /auth/signup → 500 エラー
- POST /auth/token → 401 エラー（パスワード検証失敗）
- **全ての認証機能が完全に動作不能**

### 修正内容

#### 修正ファイル1: backend/app/db/create.py
```python
# Before (passlib使用 - 動作不能)
from passlib.context import CryptContext
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
def hash_password(password: str) -> str:
    return pwd_context.hash(password)

# After (bcrypt直接使用 - 修正済み)
import bcrypt
def hash_password(password: str) -> str:
    password_bytes = password.encode('utf-8')
    salt = bcrypt.gensalt()
    hashed = bcrypt.hashpw(password_bytes, salt)
    return hashed.decode('utf-8')
```

#### 修正ファイル2: backend/app/routers/auth.py
```python
# Before (passlib使用 - 動作不能)
from passlib.context import CryptContext
pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
def verify_password(plain_password: str, hashed_password: str) -> bool:
    return pwd_context.verify(plain_password, hashed_password)

# After (bcrypt直接使用 - 修正済み)
import bcrypt
def verify_password(plain_password: str, hashed_password: str) -> bool:
    password_bytes = plain_password.encode('utf-8')
    hashed_bytes = hashed_password.encode('utf-8')
    return bcrypt.checkpw(password_bytes, hashed_bytes)
```
