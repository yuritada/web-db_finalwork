# タグ一覧ページ

**パス**: `/tags`
**ファイル**: `app/(main)/tags/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

全てのタグを一覧表示し、新規タグの作成、ユーザーへの割り当て、削除が可能なページです。タグはユーザーの分類や整理に使用されます。

---

## 🎯 主な機能

### 1. タグ一覧表示
- **グリッド形式表示**: タグをカード形式で3列グリッド表示
- **タグ名表示**: 各タグの名前
- **作成者表示**: タグを作成したユーザーID
- **アクションボタン**: 詳細、割り当て、削除（作成者のみ）

### 2. 新規タグ作成
- **新規作成ボタン**: ヘッダーに配置
- **作成モーダル**: ダイアログ形式で新規作成フォームを表示
- **タグ名入力**: 必須項目（最大100文字）
- **トースト通知**: 作成成功時にメッセージ表示

### 3. タグ割り当て
- **割り当てボタン**: 各タグカードに配置
- **割り当てモーダル**: ユーザーIDを入力して割り当て
- **トースト通知**: 割り当て成功時にメッセージ表示

### 4. タグ削除（作成者のみ）
- **削除ボタン**: 作成者のみ表示（赤色）
- **削除確認モーダル**: 削除前に確認
- **トースト通知**: 削除成功時にメッセージ表示

### 5. エラー・ローディング表示
- **ローディングスピナー**: データ取得中の表示
- **トースト通知**: エラー発生時にメッセージ表示
- **空状態**: タグが1つもない場合の案内メッセージ

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **削除権限**: 作成者のみ削除可能
- **検索・フィルタリングなし**: 現時点では全タグを表示のみ
- **ページネーションなし**: 全タグを一度に表示

## 🔌 接続先API

### 使用API

#### 1. タグ一覧取得API
- **エンドポイント**: `GET /tags`
- **レスポンス**:
  ```typescript
  TagPublic[] = [
    {
      id: number;
      name: string;
      creator_id: string;
    },
    ...
  ]
  ```

#### 2. タグ作成API
- **エンドポイント**: `POST /tags`
- **リクエスト**:
  ```typescript
  {
    name: string;  // 必須、最大100文字
  }
  ```
- **レスポンス**: 作成されたタグ情報

#### 3. タグ割り当てAPI
- **エンドポイント**: `POST /tags/{tag_id}/assign`
- **リクエスト**:
  ```typescript
  {
    user_id: string;  // 必須
  }
  ```

#### 4. タグ削除API
- **エンドポイント**: `DELETE /tags/{tag_id}`
- **レスポンス**: 削除成功メッセージ

### API関数
```typescript
// lib/api.ts
const data = await getTags();
await createTag({ name });
await assignTag(tagId, userId);
await deleteTag(tagId);
```

### UIコンポーネント

#### 1. ヘッダーセクション
- **タイトル**: "タグ管理"（3xl、太字）
- **説明文**: "タグを作成・管理して、ユーザーに割り当てることができます。"
- **新規作成ボタン**: プライマリボタン

#### 2. タグカード
- **使用コンポーネント**: `@/components/ui/card`
- **レイアウト**: 3列グリッド（タブレット: 2列、モバイル: 1列）
- **内容**:
  - タグ名（CardTitle、text-lg）
  - 作成者（CardDescription）
  - アクションボタン（詳細、割り当て、削除）

#### 3. アクションボタン
- **詳細ボタン**: アウトライン、全ユーザー表示
- **割り当てボタン**: アウトライン、全ユーザー表示
- **削除ボタン**: アウトライン、赤色、作成者のみ表示

#### 4. 新規作成モーダル
- **使用コンポーネント**: `@/components/ui/dialog`
- **タイトル**: "新しいタグを作成"
- **フォーム要素**:
  - タグ名入力欄（必須、最大100文字）
  - キャンセルボタン
  - 作成ボタン

#### 5. 割り当てモーダル
- **タイトル**: "タグを割り当て"
- **説明**: "ユーザーIDを入力して、「{タグ名}」タグを割り当てます。"
- **フォーム要素**:
  - ユーザーID入力欄（必須）
  - ヘルプテキスト: "割り当て先のユーザーIDを入力してください"
  - キャンセルボタン
  - 割り当てボタン

#### 6. 削除確認モーダル
- **タイトル**: "タグを削除"
- **警告**: "「{タグ名}」タグを削除してもよろしいですか？この操作は取り消せません。"
- **ボタン**:
  - キャンセルボタン
  - 削除ボタン（破壊的アクション、赤色）

#### 7. 空状態
- **表示条件**: タグが0件の場合
- **メッセージ**: "まだタグがありません。"
- **補足**: "「新規作成」ボタンから最初のタグを作成してみましょう。"

## 📝 備考

### 開発時の注意
- トースト通知には`sonner`ライブラリを使用
- 削除ボタンは作成者のみに表示
- モーダルの開閉状態は個別に管理

### テスト方法
1. **一覧表示**: ログイン後、タグ一覧ページにアクセス
2. **新規作成**: 「新規作成」ボタンをクリックし、フォーム入力後作成
3. **割り当て**: 「割り当て」ボタンをクリックし、ユーザーIDを入力
4. **削除**: 作成したタグの「削除」ボタンをクリック
