# タグ詳細ページ

**パス**: `/tags/[tag_id]`
**ファイル**: `app/(main)/tags/[tag_id]/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

特定のタグの詳細を表示し、そのタグが割り当てられているユーザーの一覧を確認できるページです。タグの作成者は削除やユーザー割り当ても可能です。

---

## 🎯 主な機能

### 1. タグ詳細表示
- **タグ名表示**: タグの名前
- **作成者表示**: タグを作成したユーザーID
- **タグID表示**: タグの一意識別子
- **パンくずナビゲーション**: タグ一覧へのリンク

### 2. 割り当てられたユーザー一覧
- **テーブル表示**: ユーザー情報をテーブル形式で表示
- **表示項目**:
  - ユーザー名
  - メールアドレス
  - ユーザーID
- **空状態**: ユーザーが割り当てられていない場合の案内

### 3. ユーザー割り当て機能
- **ユーザー割り当てボタン**: 全ユーザーが使用可能
- **割り当てモーダル**: ユーザーIDを入力して割り当て
- **トースト通知**: 割り当て成功時にメッセージ表示
- **自動更新**: 割り当て後、ユーザー一覧を再取得

### 4. タグ削除機能（作成者のみ）
- **削除ボタン**: 作成者のみ表示（赤色）
- **削除確認モーダル**: 削除前に確認
- **トースト通知**: 削除成功時にメッセージ表示
- **自動遷移**: 削除後、タグ一覧ページへリダイレクト

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **削除権限**: 作成者のみ削除可能
- **割り当て解除なし**: 一度割り当てたタグの解除は未実装
- **編集機能なし**: タグ名の変更は未実装

## 🔌 接続先API

### 使用API

#### 1. タグ詳細取得API
- **エンドポイント**: `GET /tags/{tag_id}`
- **レスポンス**:
  ```typescript
  TagDetail = {
    id: number;
    name: string;
    creator_id: string;
    assigned_users: AssignedUser[];  // 割り当てられたユーザーリスト
  }
  
  AssignedUser = {
    id: string;
    username: string;
    email: string;
  }
  ```

#### 2. タグ割り当てAPI
- **エンドポイント**: `POST /tags/{tag_id}/assign`
- **リクエスト**:
  ```typescript
  {
    user_id: string;  // 必須
  }
  ```

#### 3. タグ削除API
- **エンドポイント**: `DELETE /tags/{tag_id}`
- **レスポンス**: 削除成功メッセージ

### API関数
```typescript
// lib/api.ts
const data = await getTag(tagId);
await assignTag(tagId, userId);
await deleteTag(tagId);
```

```typescript
const [tag, setTag] = useState<TagDetail | null>(null);

const [isAssignModalOpen, setIsAssignModalOpen] = useState(false);
const [assignUserId, setAssignUserId] = useState('');
const [isAssigning, setIsAssigning] = useState(false);

// 削除確認モーダル
const [isDeleteModalOpen, setIsDeleteModalOpen] = useState(false);
const [isDeleting, setIsDeleting] = useState(false);
```

### 作成者判定
```typescript
const isCreator = () => {
  return tag && user && user.id === tag.creator_id;
};
```

### ユーザー割り当て処理
```typescript
const handleAssign = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!assignUserId.trim()) {
    toast.error('ユーザーIDを入力してください');
    return;
  }

  setIsAssigning(true);

  try {
    await assignTag(tagId, assignUserId.trim());
    toast.success('ユーザーにタグを割り当てました');
    setIsAssignModalOpen(false);
    setAssignUserId('');
    fetchTag(); // 一覧を再取得
  } catch (err: unknown) {
    // エラーハンドリング
  } finally {
    setIsAssigning(false);
  }
};
```

### 削除処理
```typescript
const handleDelete = async () => {
  setIsDeleting(true);

  try {
    await deleteTag(tagId);
    toast.success('タグを削除しました');
    router.push('/main/tags');
  } catch (err: unknown) {
    // エラーハンドリング
  } finally {
    setIsDeleting(false);
  }
};
```

## 📝 備考

### 開発時の注意
- 削除成功後は必ずタグ一覧ページへリダイレクト
- ユーザー割り当て後、自動的にユーザー一覧を再取得
- トースト通知には`sonner`ライブラリを使用

### テスト方法
1. **詳細表示**: タグ一覧ページから任意のタグの詳細を表示
2. **ユーザー割り当て**: 「ユーザー割り当て」ボタンをクリックし、ユーザーIDを入力
3. **削除**: 作成したタグの「削除」ボタンをクリック
