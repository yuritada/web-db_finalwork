# チャンネル一覧ページ

**パス**: `/channels`
**ファイル**: `app/(main)/channels/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

全てのチャンネルを一覧表示し、新規チャンネルの作成が可能なページです。テーマ別のチャンネルでメッセージを共有できます。

---

## 🎯 主な機能

### 1. チャンネル一覧表示
- **グリッド形式表示**: チャンネルをカード形式で3列グリッド表示
- **チャンネル名表示**: 各チャンネルの名前
- **説明表示**: チャンネルの説明文
- **プライベートバッジ**: プライベートチャンネルには鍵アイコン表示
- **クリック遷移**: カードをクリックするとチャンネル詳細ページへ遷移

### 2. 新規チャンネル作成
- **新規作成ボタン**: ヘッダーに配置
- **作成モーダル**: ダイアログ形式で新規作成フォームを表示
- **チャンネル名入力**: 必須項目（最大100文字）
- **説明入力**: 任意項目（最大500文字）
- **トースト通知**: 作成成功時にメッセージ表示

### 3. エラー・ローディング表示
- **ローディングスピナー**: データ取得中の表示
- **トースト通知**: エラー発生時にメッセージ表示
- **空状態**: チャンネルが1つもない場合の案内メッセージ

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **削除機能なし**: 一覧ページからの削除は不可
- **検索・フィルタリングなし**: 現時点では全チャンネルを表示のみ
- **ページネーションなし**: 全チャンネルを一度に表示

---

## 🔌 接続先API

### 使用API

#### 1. チャンネル一覧取得API
- **エンドポイント**: `GET /channels`
- **レスポンス**:
  ```typescript
  ChannelPublic[] = [
    {
      id: number;
      name: string;
      description?: string;
      is_private: boolean;
    },
    ...
  ]
  ```

#### 2. チャンネル作成API
- **エンドポイント**: `POST /channels`
- **リクエスト**:
  ```typescript
  {
    name: string;          // 必須、最大100文字
    description?: string;  // 任意、最大500文字
  }
  ```
- **レスポンス**: 作成されたチャンネル情報

### API関数
```typescript
// lib/api.ts
const data = await getChannels();
await createChannel({ name, description });
```

## 📝 備考

### 開発時の注意
- カード全体をクリッカブルにする
- トースト通知には`sonner`ライブラリを使用
- ChannelCardコンポーネントを再利用

### テスト方法
1. **一覧表示**: ログイン後、チャンネル一覧ページにアクセス
2. **新規作成**: 「新規作成」ボタンをクリックし、フォーム入力後作成
3. **遷移**: チャンネルカードをクリックして詳細ページへ遷移
