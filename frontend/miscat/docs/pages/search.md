# 検索ページ

**パス**: `/search`
**ファイル**: `app/(main)/search/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

Wiki、タグ、ユーザーを横断的に検索できるページです。キーワードを入力し、検索対象を指定することで、該当する結果を一覧表示します。

---

## 🎯 主な機能

### 1. 検索フォーム
- **キーワード入力**: 検索したいキーワードを入力（必須）
- **検索対象選択**: すべて、Wiki、タグ、ユーザーから選択
- **検索ボタン**: 検索を実行

### 2. 検索結果表示
- **結果件数表示**: 検索結果の総数を表示
- **結果一覧**: 検索結果をカード形式で表示
- **タイプアイコン**: 各結果のタイプをアイコンで表示（📄Wiki、🏷️タグ、👤ユーザー）
- **タイプラベル**: 各結果のタイプをバッジで表示
- **詳細情報**:
  - Wiki: タイトル、スニペット（抜粋）
  - タグ: タグ名
  - ユーザー: ユーザー名、メールアドレス

### 3. 結果クリック
- **Wikiクリック**: Wiki詳細ページへ遷移
- **タグクリック**: タグ詳細ページへ遷移
- **ユーザー**: クリック不可（詳細ページなし）

### 4. トースト通知
- **検索成功**: 「{件数}件の結果が見つかりました」
- **結果なし**: 「検索結果が見つかりませんでした」
- **エラー**: 「検索に失敗しました」

### 5. エラー・ローディング表示
- **ローディングスピナー**: 検索実行中の表示
- **空状態**: 検索結果が0件の場合の案内メッセージ

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **ユーザー詳細ページなし**: ユーザー結果はクリックできない
- **高度な検索なし**: AND/OR検索、フレーズ検索などは未実装
- **検索履歴なし**: 過去の検索履歴保存は未実装
- **ページネーションなし**: 全結果を一度に表示

---

## 🔌 接続先API

### 使用API

#### 1. 検索API
- **エンドポイント**: `GET /search`
- **クエリパラメータ**:
  - `q`: 検索キーワード（必須）
  - `type`: 検索対象（`wiki` | `tag` | `user` | `all`、デフォルト: `all`）
- **レスポンス**:
  ```typescript
  SearchResponse = {
    results: SearchResult[];
    total: number;
  }
  
  SearchResult = {
    type: 'wiki' | 'tag' | 'user';
    id: string | number;
    title?: string;       // Wiki用
    name?: string;        // タグ用
    username?: string;    // ユーザー用
    email?: string;       // ユーザー用
    snippet?: string;     // Wiki用（抜粋）
  }
  ```

### API関数
```typescript
// lib/api.ts
const response = await search(query, searchType);
```

## 🔧 実装詳細

### 状態管理
```typescript
const [query, setQuery] = useState('');
const [searchType, setSearchType] = useState<'wiki' | 'tag' | 'user' | 'all'>('all');
const [results, setResults] = useState<SearchResult[]>([]);
const [total, setTotal] = useState(0);
const [isSearching, setIsSearching] = useState(false);
const [hasSearched, setHasSearched] = useState(false);
```

### 検索処理
```typescript
const handleSearch = async (e: React.FormEvent) => {
  e.preventDefault();

  if (!query.trim()) {
    toast.error('検索キーワードを入力してください');
    return;
  }

  setIsSearching(true);
  setHasSearched(true);

  try {
    const response = await search(query.trim(), searchType);
    setResults(response.results);
    setTotal(response.total);

    if (response.total === 0) {
      toast.info('検索結果が見つかりませんでした');
    } else {
      toast.success(`${response.total}件の結果が見つかりました`);
    }
  } catch (err: unknown) {
    // エラーハンドリング
  } finally {
    setIsSearching(false);
  }
};
```

## 📝 備考

### 開発時の注意
- ユーザー結果はクリックできないようにする
- 検索結果が表示されるのは検索実行後のみ
- トースト通知には`sonner`ライブラリを使用

### テスト方法
1. **Wiki検索**: キーワードを入力し、検索対象を「Wiki」に設定
2. **タグ検索**: キーワードを入力し、検索対象を「タグ」に設定
3. **全体検索**: キーワードを入力し、検索対象を「すべて」に設定
4. **結果クリック**: Wiki/タグ結果をクリックして遷移確認
