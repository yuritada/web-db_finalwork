# サインアップページ（新規登録ページ）

**パス**: `/signup`
**ファイル**: `app/(auth)/signup/page.tsx`
**認証**: 不要（誰でもアクセス可能）

---

## 📋 概要

新規ユーザーがアカウントを作成するためのページです。ユーザー名、メールアドレス、パスワード、ユーザー区分などの情報を入力し、アカウントを登録します。登録成功後はメインダッシュボード（`/main`）へリダイレクトされます。

---

## 🎯 主な機能

### 1. サインアップフォーム
- **ユーザー名入力**: 3-100文字のユーザー名を入力
- **メールアドレス入力**: 有効なメールアドレスを入力
- **パスワード入力**: 8文字以上のパスワードを入力
- **パスワード確認入力**: パスワードを再入力して一致確認
- **ユーザー区分選択**: 学生、教授、准教授、講師、事務から選択
- **学籍番号入力**: 学生の場合のみ表示（任意）
- **学部・所属入力**: 任意項目

### 2. パスワード強度インジケーター
- **リアルタイム評価**: 入力されたパスワードの強度を評価
- **評価基準**:
  - 長さ（8文字以上、12文字以上）
  - 小文字の使用
  - 大文字の使用
  - 数字の使用
  - 記号の使用
- **視覚的表示**: プログレスバーとラベル（弱い/普通/強い）

### 3. 入力バリデーション
- **必須項目チェック**: ユーザー名、メール、パスワード、ユーザー区分
- **ユーザー名**: 3-100文字
- **メール形式チェック**: 正規表現による簡易バリデーション
- **パスワード長**: 8文字以上
- **パスワード一致**: パスワードと確認用パスワードの一致確認
- **エラー表示**: バリデーションエラーやサインアップ失敗時にエラーメッセージを表示

### 4. 条件付きフィールド表示
- **学籍番号**: ユーザー区分が「学生」の場合のみ表示

### 5. 自動リダイレクト
- **サインアップ成功**: メインダッシュボード（`/main`）へリダイレクト

### 6. ローディング状態
- **登録中表示**: ボタンテキストが「登録中...」に変化
- **フォーム無効化**: 送信中は入力フィールドとボタンを無効化

---

## 🔒 制限事項

### アクセス制限
- **制限なし**: 誰でもアクセス可能
- **認証済みユーザー**: アクセス可能だが、通常は使用しない

### 機能制限
- **メール確認なし**: メールアドレスの確認は未実装
- **OAuth登録なし**: Google、Githubなどの外部サービス連携は未実装
- **招待制なし**: 誰でも登録可能

### バリデーション制限
- **メールの実在確認なし**: フォーマットチェックのみ
- **ユーザー名の重複チェック**: サーバー側でのみ実施

## 🔌 接続先API

### 使用API

#### 1. サインアップAPI
- **エンドポイント**: `POST /auth/signup`
- **リクエスト**:
  ```typescript
  {
    username: string;          // 3-100文字
    email: string;             // メールアドレス形式
    password: string;          // 8文字以上
    kategori: UserKategori;    // STUDENT | PROFESSOR | ASSOCIATE_PROFESSOR | LECTURER | STAFF
    gakuseki_bango?: string;   // 学籍番号（任意）
    faculty?: string;          // 学部・所属（任意）
  }
  ```
- **レスポンス**:
  - `200 OK`: サインアップ成功
  - `400 Bad Request`: バリデーションエラー、既存ユーザー重複
  - `422 Unprocessable Entity`: バリデーションエラー

### API関数
```typescript
// lib/api.ts
await signup({
  username,
  email,
  password,
  kategori: kategori as UserKategori,
  gakuseki_bango: gakusekiBango || undefined,
  faculty: faculty || undefined,
});
```

### パスワード強度計算
```typescript
function calculatePasswordStrength(password: string): { score: number; label: string; color: string } {
  let score = 0;

  if (password.length >= 8) score += 1;
  if (password.length >= 12) score += 1;
  if (/[a-z]/.test(password)) score += 1;
  if (/[A-Z]/.test(password)) score += 1;
  if (/[0-9]/.test(password)) score += 1;
  if (/[^a-zA-Z0-9]/.test(password)) score += 1;

  if (score <= 2) return { score, label: '弱い', color: 'bg-red-500' };
  if (score <= 4) return { score, label: '普通', color: 'bg-yellow-500' };
  return { score, label: '強い', color: 'bg-green-500' };
}
```

### フォーム送信処理
```typescript
const handleSubmit = async (e: React.FormEvent) => {
  e.preventDefault();
  setError('');
  setIsLoading(true);

  try {
    // バリデーション
    if (!username || !email || !password || !confirmPassword || !kategori) {
      setError('全ての必須項目を入力してください');
      setIsLoading(false);
      return;
    }

    if (username.length < 3 || username.length > 100) {
      setError('ユーザー名は3文字以上100文字以内で入力してください');
      setIsLoading(false);
      return;
    }

    if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email)) {
      setError('有効なメールアドレスを入力してください');
      setIsLoading(false);
      return;
    }

    if (password.length < 8) {
      setError('パスワードは8文字以上で入力してください');
      setIsLoading(false);
      return;
    }

    if (password !== confirmPassword) {
      setError('パスワードが一致しません');
      setIsLoading(false);
      return;
    }

    // サインアップ実行
    await signup({
      username,
      email,
      password,
      kategori: kategori as UserKategori,
      gakuseki_bango: gakusekiBango || undefined,
      faculty: faculty || undefined,
    });

    // サインアップ成功後、メインページへリダイレクト
    router.push('/main');
  } catch (err: unknown) {
    // エラーハンドリング
    if (err instanceof Error) {
      setError(err.message || 'サインアップに失敗しました');
    } else {
      setError('サインアップに失敗しました');
    }
  } finally {
    setIsLoading(false);
  }
};
```

## 📝 備考

### 開発時の注意
- サインアップ成功後は自動ログインされる
- パスワード強度インジケーターはガイダンスのみ（制限は8文字以上）
- 学籍番号は学生以外では自動生成される（バックエンド側）
- エラーメッセージは具体的に表示

### テスト方法
1. **正常系**: 全ての必須項目を入力してアカウント作成
2. **異常系**:
   - 必須項目を空欄 → バリデーションエラー
   - ユーザー名が3文字未満 → バリデーションエラー
   - メール形式が不正 → バリデーションエラー
   - パスワードが8文字未満 → バリデーションエラー
   - パスワードが一致しない → バリデーションエラー
   - 既存のメールアドレス → APIエラー

### セキュリティ
- パスワードはHTTPSで送信（本番環境）
- パスワードはbcryptでハッシュ化（バックエンド側）
- トークンはHttpOnly Cookieで管理（XSS攻撃対策）
