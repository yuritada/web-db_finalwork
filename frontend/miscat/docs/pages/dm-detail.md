# DM詳細ページ

**パス**: `/dm/[dm_id]`
**ファイル**: `app/(main)/dm/[dm_id]/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

特定のユーザーとのダイレクトメッセージ（DM）の履歴を表示し、メッセージの送受信ができるページです。1対1の会話が行えます。

---

## 🎯 主な機能

### 1. 相手ユーザー情報表示
- **ユーザー名表示**: 会話相手のユーザー名
- **ユーザーID表示**: 会話相手のユーザーID
- **パンくずナビゲーション**: DM一覧へのリンク

### 2. メッセージ履歴表示
- **MessageListコンポーネント**: メッセージをリスト形式で表示
- **送信者情報**: 送信者のユーザー名
- **メッセージ内容**: メッセージ本文
- **タイムスタンプ**: 送信日時
- **自分のメッセージ**: 右側に表示、青色背景
- **相手のメッセージ**: 左側に表示、グレー背景

### 3. メッセージ送信
- **MessageInputコンポーネント**: メッセージ入力欄と送信ボタン
- **リアルタイム送信**: 送信後、即座にメッセージリストに追加
- **トースト通知**: エラー発生時にメッセージ表示

### 4. エラー・ローディング表示
- **ローディングスピナー**: データ取得中の表示
- **トースト通知**: エラー発生時にメッセージ表示

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **メッセージ編集なし**: 送信後の編集は未実装
- **メッセージ削除なし**: 送信後の削除は未実装
- **ファイル添付なし**: テキストメッセージのみ
- **リアルタイム更新なし**: WebSocket未実装（手動更新が必要）
- **既読管理なし**: 既読・未読の管理は未実装

## 🔌 接続先API

### 使用API

#### 1. DMメッセージ履歴取得API
- **エンドポイント**: `GET /messages/dm/{user_id}`
- **パラメータ**: `user_id` - 会話相手のユーザーID
- **レスポンス**:
  ```typescript
  Message[] = [
    {
      id: number;
      sender_id: string;
      sender_username: string;
      content: string;
      created_at: string;
    },
    ...
  ]
  ```

#### 2. DMメッセージ送信API
- **エンドポイント**: `POST /messages/dm`
- **リクエスト**:
  ```typescript
  {
    receiver_id: string;  // 必須、会話相手のユーザーID
    content: string;      // 必須
  }
  ```
- **レスポンス**: 送信されたメッセージ情報

### API関数
```typescript
// lib/api.ts
const data = await getDMMessages(partnerId);
const newMessage = await sendDMMessage({ receiver_id: partnerId, content });
```

## 🔧 実装詳細

### 状態管理
```typescript
const [messages, setMessages] = useState<Message[]>([]);
const [isLoading, setIsLoading] = useState(true);
const [partnerUsername, setPartnerUsername] = useState('');

const partnerId = resolvedParams.dm_id;
```

### メッセージ送信処理
```typescript
const handleSendMessage = async (content: string) => {
  try {
    const newMessage = await sendDMMessage({
      receiver_id: partnerId,
      content,
    });

    // メッセージリストに追加
    setMessages([...messages, newMessage]);
  } catch (err: unknown) {
    // エラーハンドリング
  }
};
```

### 相手ユーザー名の取得
```typescript
// メッセージ履歴から推測
if (data.length > 0) {
  const partnerMessage = data.find(m => m.sender_id === partnerId);
  if (partnerMessage) {
    setPartnerUsername(partnerMessage.sender_username);
  }
}
```

- MessageListとMessageInputコンポーネントを再利用（チャンネルと共通）
