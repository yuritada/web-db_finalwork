# DM一覧ページ

**パス**: `/dm`
**ファイル**: `app/(main)/dm/page.tsx`
**認証**: 必須（ログインユーザーのみアクセス可能）

---

## 📋 概要

ダイレクトメッセージ（DM）の会話一覧を表示するページです。他のユーザーと1対1でメッセージを送受信できます。

---

## 🎯 主な機能

### 1. DM会話一覧表示
- **グリッド形式表示**: DM会話をカード形式で3列グリッド表示
- **相手ユーザー名表示**: 会話相手のユーザー名
- **最終メッセージ表示**: 最後に送受信したメッセージの内容
- **最終メッセージ日時**: 最後にメッセージが送受信された日時
- **未読件数表示**: 未読メッセージ数（実装予定）
- **クリック遷移**: カードをクリックするとDM詳細ページへ遷移

### 2. エラー・ローディング表示
- **ローディングスピナー**: データ取得中の表示
- **トースト通知**: エラー発生時にメッセージ表示
- **空状態**: DMが1つもない場合の案内メッセージ

---

## 🔒 制限事項

### アクセス制限
- **認証必須**: 未認証ユーザーはアクセス不可

### 機能制限
- **新規DM開始ボタンなし**: 検索ページから開始する必要がある
- **未読管理未実装**: 未読カウントは表示されるが、管理は未実装
- **検索・フィルタリングなし**: 現時点では全会話を表示のみ
- **ページネーションなし**: 全会話を一度に表示

## 🔌 接続先API

### 使用API

#### 1. DM会話一覧取得API
- **エンドポイント**: `GET /messages/dm`
- **レスポンス**:
  ```typescript
  DMConversation[] = [
    {
      user_id: string;          // 相手のユーザーID
      username: string;         // 相手のユーザー名
      last_message?: string;    // 最終メッセージ内容
      last_message_at?: string; // 最終メッセージ日時
      unread_count?: number;    // 未読件数
    },
    ...
  ]
  ```

### API関数
```typescript
// lib/api.ts
const data = await getDMConversations();
```

## 📝 備考

### 開発時の注意
- DMCardコンポーネントを再利用
- 相手のユーザーIDを使用してDM詳細ページへ遷移
- トースト通知には`sonner`ライブラリを使用

### テスト方法
1. **一覧表示**: ログイン後、DM一覧ページにアクセス
2. **遷移**: DMカードをクリックして詳細ページへ遷移
3. **空状態**: DM会話がない状態で表示確認
