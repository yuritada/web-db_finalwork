# トップページ（ウェルカムページ）

**パス**: `/`
**ファイル**: `app/page.tsx`
**認証**: 不要（誰でもアクセス可能）

---

## 📋 概要

Miscatアプリケーションのトップページ（ランディングページ）です。未認証ユーザー向けのウェルカム画面で、ログインまたは新規登録（サインアップ）を選択できます。

---

## 🎯 主な機能

### 1. ログイン/サインアップ選択
- **ログインボタン**: `/login` ページへ遷移
- **新規登録ボタン**: `/signup` ページへ遷移

### 2. 自動リダイレクト
- **認証済みユーザー**: 自動的に `/main` （メインダッシュボード）へリダイレクト
- **未認証ユーザー**: ウェルカムページを表示

### 3. ローディング表示
- 認証状態の確認中はローディングスピナーを表示

---

## 🔒 制限事項

### アクセス制限
- **制限なし**: 誰でもアクセス可能
- **認証済みユーザー**: 自動的にメインページへリダイレクトされる

### 機能制限
- このページでは実際の機能は提供されない
- ナビゲーション用のエントリーポイントとして機能

---

## 🔌 接続先API

### 使用API
- **なし（直接的には使用しない）**

### 認証コンテキスト
- `AuthContext` を使用して認証状態を確認
  - `isAuthenticated`: 認証済みかどうか
  - `isLoading`: 認証状態の読み込み中かどうか

|-----------|--------|------|------|
| ログインボタンクリック | ログインページ | `/login` | 既存ユーザーのログイン |

- **ブラウザバック**: 前のページへ戻る（通常はない）

## 🔧 実装詳細

### 状態管理
```typescript
const { isAuthenticated, isLoading } = useAuth();
```

### リダイレクトロジック
```typescript
useEffect(() => {
  if (!isLoading && isAuthenticated) {
    router.push('/main');
  }
}, [isAuthenticated, isLoading, router]);
```

### 条件分岐
1. **ローディング中**: スピナー表示
2. **認証済み**: `null` を返す（リダイレクト中）
3. **未認証**: ウェルカムページ表示

---

## 📝 備考

### 開発時の注意
- 認証状態の確認は`AuthContext`に依存
- `isLoading`が`false`になるまでリダイレクトを実行しない
- ログインボタンとサインアップボタンのスタイルを区別

### テスト方法
1. **未認証状態**: ブラウザでトップページにアクセス
2. **認証済み状態**: ログイン後、ルート`/`にアクセスして自動リダイレクトを確認
